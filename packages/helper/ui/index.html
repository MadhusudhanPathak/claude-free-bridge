Set up in three steps

Claude Free Bridge lets apps on this computer use your claude.ai account through your browser. Keep this app running while you use it. Each step ticks itself off when it's done.

  1. 1

    Add the extension to your browser

    Works in Microsoft Edge, Brave, Chrome and other Chromium browsers.

    1. Open your browser's extensions page by pasting its address into the address bar:
      Click one to copy it.
    2. Turn on Developer mode, using the switch on that page.
    3. Click Load unpacked and choose this folder:
      …
    4. Pin it to the toolbar: click the puzzle-piece icon, then the pin next to Claude Free Bridge.

  2. 2

    Connect the extension to this app

    Click the Claude Free Bridge icon in your browser's toolbar. In the panel that opens, paste this pairing code and click Connect.

  3. 3

    Log in to claude.ai

    In the same browser, make sure you're logged in at claude.ai.

You're all set

Try it in the Playground, or connect your own apps.

Use with your apps

Apps and scripts that can use the OpenAI or Anthropic API can use Claude Free Bridge instead. Give them these settings:

API key
Base URL for OpenAI-compatible apps
Base URL for Anthropic-compatible apps
Model
claude-web

Uses your claude.ai account's default model.

Good to know

        
    
          
  • Each request starts a new chat in your claude.ai history, named “API · …”. To delete these automatically, open the extension's panel and go to Settings.
    • 
          
  • Text only for now. Images, files and tool calls aren't supported yet, so coding agents that rely on tools (Claude Code, Cline…) can chat but can't use their tools.
    • 
          
  • Requests run one at a time and count toward your claude.ai usage limits.
    • 
          
  • The API only answers apps on this computer. Keep your API key private.
